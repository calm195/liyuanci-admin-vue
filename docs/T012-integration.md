# T012 身份审核页接入清单

关联 REQ-002、018、019；前置 T010、T011（并等待 T008 真实后台身份）。2026-10-21 已按用户授权完成受角色守卫保护的本地合成业务页（列表、详情、按需读卡、决定与回执），以隔离 Mock 先开发业务；未启用真实适配器，不申报真实联调验收。

采用共享契约 0.1.0：

| 操作                                                 | 接入与验证条件                                                                                                                                |
| ---------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| GET /api/v1/admin/identity-reviews                   | 游标分页、脱敏列表、空/加载/失败/重试状态；不得把完整姓名/学号/卡放入列表                                                                     |
| GET /api/v1/admin/identity-reviews/{id}              | 当前案件授权后读取 IdentityCase，限组件短暂状态；离开、401/403、换案或退出立即清空；取消请求，拒绝过期响应                                    |
| GET /api/v1/admin/identity-reviews/{id}/student-card | 后端验证当前角色及案件并记录查看；代理二进制读取，no-store；不产生可复用公开地址。若使用 blob URL，切案/离开立即 revoke；不写浏览器存储或日志 |
| POST /api/v1/admin/identity-reviews/{id}/decision    | approved/rejected + expected_version，写入带 Idempotency-Key；驳回 reason/revision_suggestion 均非空；409重新获取当前版本，禁止自动重试旧决定 |

实施前由后端提供 T011 接受证据：私有对象/加密与失败关闭、场景权限、审计、审核版本一致性。确认 T008 活跃会话与401/403/404语义。审核运营/超管允许；仅危机角色拒绝，复合角色按实际授权判断。

联调用例：002-A/B/C、018-A–F 适用部分、019-A/B、契约 C01/C06；包括停用账号/撤销令牌/角色收回、越权换案/读卡、旧版本409、请求晚到、弱网重复提交、无身份泄漏检查。模拟通过不证明后端授权正确。

无认证审核时限，不显示虚构倒计时；不接全站私聊、延期模块或无目的身份导出。T011 未验收前仅开放显式 DEV Mock 的合成业务流程，生产失败关闭；真实适配器待二进制与脱敏列表样例确认后接入。

## 本地人工验证

1. 执行 `VITE_ADMIN_MOCK=true pnpm dev`，以审核运营或超管登录，进入“身份审核”。页面持续显示合成标记。
2. 首屏列表只有案件编号、状态和版本，无姓名、学号和卡图。切换上下页，确认分页不重复。
3. 打开案件后才显示合成身份；点击“查看学生卡”才显示合成卡图。收起、切案、关闭、翻页、离开或退出后，原资料与图片消失。
4. 选择驳回，仅空白原因或建议不能进入确认。填写两项，点击“核对决定”，检查案件编号、版本、决定和文案；可返回修改，再“确认提交”。
5. 确认显示已驳回回执及原因/建议，列表版本递增。重新打开已处理案件只读。另一案件可测试通过流程。
6. 退出后以危机角色登录，菜单无身份审核；直接访问 `/identity` 进入403。刷新需重新登录，离开并重新进入业务页会重新生成合成案件。
7. 停止服务，以 `VITE_ADMIN_MOCK=false pnpm dev` 重启，真实登录仍禁用。`pnpm build` 的产物始终禁用 Mock。

取消、晚到响应、409、弱网重试与401/403清理通过合成组件测试验证；本地演示不伪造真实后端故障或审计证据。学生卡真实类型/大小/缓存头、逐请求案件授权、持久幂等和查看审计仍需真实接口联调。

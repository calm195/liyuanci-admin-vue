# T012 身份审核页接入清单

关联 REQ-002、018、019；前置 T010、T011（并等待 T008 真实后台身份）。当前只交付受角色守卫保护的接入说明页，没有真实身份审核功能，不申报 T012 验收。

采用共享契约 0.1.0：

| 操作                                                 | 接入与验证条件                                                                                                                                |
| ---------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| GET /api/v1/admin/identity-reviews                   | 游标分页、脱敏列表、空/加载/失败/重试状态；不得把完整姓名/学号/卡放入列表                                                                     |
| GET /api/v1/admin/identity-reviews/{id}              | 当前案件授权后读取 IdentityCase，限组件短暂状态；离开、401/403、换案或退出立即清空；取消请求，拒绝过期响应                                    |
| GET /api/v1/admin/identity-reviews/{id}/student-card | 后端验证当前角色及案件并记录查看；代理二进制读取，no-store；不产生可复用公开地址。若使用 blob URL，切案/离开立即 revoke；不写浏览器存储或日志 |
| POST /api/v1/admin/identity-reviews/{id}/decision    | approved/rejected + expected_version，写入带 Idempotency-Key；驳回 reason/revision_suggestion 均非空；409重新获取当前版本，禁止自动重试旧决定 |

实施前由后端提供 T011 接受证据：私有对象/加密与失败关闭、场景权限、审计、审核版本一致性。确认 T008 活跃会话与401/403/404语义。审核运营/超管允许；仅危机角色拒绝，复合角色按实际授权判断。

联调用例：002-A/B/C、018-A–F 适用部分、019-A/B、契约 C01/C06；包括停用账号/撤销令牌/角色收回、越权换案/读卡、旧版本409、请求晚到、弱网重复提交、无身份泄漏检查。模拟通过不证明后端授权正确。

无认证审核时限，不显示虚构倒计时；不接全站私聊、延期模块或无目的身份导出。T011 未验收前维持当前准备页。

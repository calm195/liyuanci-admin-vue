# 默认开放真实后台接口

2026-10-21；T010/T012/T011，REQ-002、018、019、020。用户明确要求开启真实登录并删除同类环境限制；沿用契约 0.2.0，不修改后端及共享工作台。

## 主要行为与边界

- 登录、本人改密、退出、账号列表/创建/角色完整替换、身份审核列表/详情/学生卡/决定默认连接同源 `/api/v1`，开发、预览与生产构建一致。
- 删除 DEV、mode=integration、VITE_ADMIN_AUTH_INTEGRATION 和 VITE_ADMIN_IDENTITY_INTEGRATION 对真实接口的限制；删除通用后台请求仅允许退出的白名单。旧环境开关不再参与运行时判断，并从类型和配置示例移除。
- 登录表单和本人改密表单不再因未开启联调或非 Mock 而禁用；身份审核默认加载真实队列，账号页面按超管权限加载。移除相应“待验收开放”“隔离联调”页面文案。
- 开发时显式 VITE_ADMIN_MOCK=true 仍选择合成演示，模拟令牌不发送至真实接口；账号管理不提供模拟模型。生产忽略 Mock 开关，始终使用真实接口。
- 权限及协议校验保持适用：超管菜单/路由、后台 Bearer、内存会话、401清理、403停止、稳定幂等键、目标版本、二次确认、迟到响应丢弃、取消及敏感状态清理。
- 内容审核和词库尚无真实 HTTP 客户端，仍仅 Mock；本阶段未将模拟服务冒充真实接口，也未新增后端功能。

## 模块与设计取舍

admin.ts 在非 Mock 时直接调用既有真实身份传输，不再依赖隔离环境准入。realApiEnabled 仅区分显式开发 Mock 与真实接口，供账号页面使用；身份审核直接按 mockEnabled 选择合成或真实传输。LoginView、PasswordView 移除额外表单禁用条件。accounts.ts、admin-auth-transport.ts 更新接线说明；输入/输出契约、错误状态和同源路径不变。

无需新增运行参数：`pnpm dev` 即使用真实接口，`pnpm build` 后同样生效。部署方须提供同源 `/api/v1` 转发及相应后台路由，前端不硬编码主机、不新增代理、账号或口令。仓库未提供运行中的后端地址或凭据，因而本轮未执行真实账号登录。

## 验证

`pnpm format`、`pnpm check`、`pnpm build` 均通过：17 个业务测试文件、172 个测试，规范检查器58个测试。

环境矩阵验证默认开发/生产及 production 下错误配置 Mock 时仍调用真实接口，旧开关为 false 不再阻断。真实登录表单的成功和401路径通过传输桩验证，提交后清空口令；本人改密页面回归改为非 Mock 执行，覆盖成功清会话、错误旧口令、重复提交、幂等重试、取消和会话变更。新增真实身份审核页面接线测试，进入页读取队列、按需读取详情并携带后台 Bearer。账号权限、身份材料及现有模拟边界回归均通过。

## 状态与依赖

这是前端默认入口开放，不宣称后端部署、审计、数据库、供应商或三端联调验收完成。账号/人工认证路由需后端实际启用，内容审核和词库真实接线仍未实现。此前阶段文档中的隔离准入和生产关闭说明作为历史保留，以本阶段为当前行为。同步更新中英文 README、配置示例及本阶段英文文档。仅修改本仓库，提交后不 push、不部署或上线。

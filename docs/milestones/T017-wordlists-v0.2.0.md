## 字段及行为迁移

| 0.1.0 本地旧模型                               | 0.2.0 本轮消费                                                                                                          |
| ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 以同分类最高资源版本作创建基准，新分类省略版本 | 每页独立返回 crisis/school/ordinary_violation 三个 heads；首次也带对应 head.version，初始为1/null                       |
| 创建资源版本取最高版本+1                       | 草稿资源版本从1开始；创建只推进 head.version，生效id不变，记录 base_effective_id                                        |
| 发布只带资源版本、拒绝所有较早草案             | 同时带 expected_version 与 expected_head_version，并核验 base_effective_id 等于当前生效id；存在较晚草案本身不否决旧草案 |
| 发布归档旧项，列表推断生效                     | 同步推进新/旧资源状态版本、head代次和生效指针；旧生效版归档，不能直接重发或一键回滚                                     |
| 无词条详情、状态字符串开放                     | WordlistDetail 完整 entries，三种状态枚举，draft/published/archived 授权只读详情；非法或缺失响应字段在边界拒绝          |
| 本地匹配只回版本数字                           | 合成匹配回实际快照 id/version；后续调用使用新生效版，旧匹配结果不改写，不触发历史全量重扫                               |

输入始终为完整不可变词条快照，允许空数组；页面不将只读详情作为可修改旧资源。列表投影不携带 entries，详情响应复制数组，调用方修改不会改变内部快照。合成种子标明为已发布历史快照，资源版本2/head代次3；新分类为head代次1且生效id为空。

页面独立显示分类基准、生效id、资源版本和创建时生效id，确认框展示双版本。所有游标页读取成功且 heads 一致后才可写入；跨页基准变化、缺失、重复或分页循环均拒绝使用部分列表。409/404 清确认并重读，用户重新核对后才能发新请求，不自动升级版本或覆盖。旧生效版草案只读并提示创建新快照。沿用幂等键、重复提交锁、401/403清理、会话绑定；详情切换/关闭/离开取消并拒绝晚到响应。

模块边界：`types/wordlists.ts` 定义 wire 类型；`services/wordlists.ts` 做响应校验和页面实例内合成状态；`WordlistsView.vue` 持有表单、详情及确认状态；未修改共享store、路由权限或后端。没有新依赖，没有真实HTTP、替代网络传输或持久化，不声称数据库原子性、审计与真实扫描已实现。

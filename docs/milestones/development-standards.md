# 开发规范自动检查

日期：2026-10-20。范围：非测试代码编号、中文注释与日志规范，无新增业务需求编号。

## 行为与边界

本地 ESLint 规则随 `pnpm lint`、`pnpm check` 及现有 CI 执行，发现违规返回失败。覆盖 JS、TS、JSX、TSX、Vue、独立 CSS/HTML 与工程脚本，豁免测试文件及依赖、构建产物。全文检查任务、需求、接入决策编号，包含注释、Vue 模板及样式块；检查脚本、HTML 与 CSS 说明注释；HTML 内联脚本独立交给脚本解析器检查，保留原文行列位置。检查 `console`、`logger`、`log` 的 log/info/warn/error/debug/trace/fatal 调用。三斜线类型引用保持原文。

日志首参必须是含中文的静态字符串或模板，动态数据放在后续参数。日志别名按变量作用域迭代追踪，支持赋值、解构、链式别名、命名导入别名、条件表达式、可选链、静态计算属性和 bind/call/apply；支持 Vue 模板引用脚本别名。重赋值保守保留来源，不把其他作用域的同名变量当作别名。中文检测只能判断是否含中文，不能判断业务表达质量；新增日志封装需要扩展规则。不进行跨文件、跨 HTML 脚本块、任意对象属性或函数参数/返回值的数据流分析，禁止利用这些形式绕过规范。

## 设计与验证

复用现有 ESLint、Vue 解析器和 jsdom，不增加依赖或改变锁文件。HTML 使用文档解析边界提取注释、样式与脚本，不执行脚本或加载外部资源；CSS 注释扫描跳过字符串、转义与地址内容，避免误报。文本入口只提供规范检查所需的注释与原文，不代替完整 HTML/CSS 语法校验。规则仅报告，不自动修改业务代码。使用 ESLint RuleTester 验证允许和拒绝场景，使用实际配置验证非测试源码拦截、原文件定位与测试文件豁免。规范测试使用 Node 内置测试运行器，并入 `pnpm test`，业务测试继续由 Vitest 执行。

接口契约与真实/模拟状态不变，无外部接入依赖。验证通过：`pnpm format`、`pnpm check`（格式、零警告 lint、严格类型、20 个业务用例与 58 个规范用例）、`pnpm build`、`git diff --check`。未在远端运行 CI。

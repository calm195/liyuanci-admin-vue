# 开发规范自动检查

日期：2026-10-20。范围：非测试代码编号、中文注释与日志规范，无新增业务需求编号。

## 行为与边界

本地 ESLint 规则随 `pnpm lint`、`pnpm check` 及现有 CI 执行，发现违规返回失败。覆盖 JS、TS、JSX、TSX、Vue 与工程脚本，豁免测试文件及依赖、构建产物。全文检查任务、需求、接入决策编号，包含注释和 Vue 模板；检查脚本说明注释与模板注释；检查 `console`、`logger`、`log` 的 log/info/warn/error/debug/trace/fatal 调用。三斜线类型引用保持原文。

日志首参必须是含中文的静态字符串或模板，动态数据放在后续参数。中文检测只能判断是否含中文，不能判断业务表达质量；新增日志封装需要扩展规则。当前不解析独立 CSS/HTML 文件或 Vue 样式块，不进行日志别名的数据流追踪，相关内容仍遵循人工规范。

## 设计与验证

复用现有 ESLint 与 Vue 解析器，不增加依赖或改变锁文件；规则仅报告，不自动修改业务代码。使用 ESLint RuleTester 验证允许和拒绝场景，使用实际配置验证非测试源码拦截与测试文件豁免。规范测试使用 Node 内置测试运行器，并入 `pnpm test`，业务测试继续由 Vitest 执行。

接口契约与真实/模拟状态不变，无外部接入依赖。验证通过：`pnpm format`、`pnpm check`（格式、零警告 lint、严格类型、20 个业务用例与 15 个规范用例）、`pnpm build`、`git diff --check`。未在远端运行 CI。

# T012

## 身份审核业务页面（2026-10-21）

第二阶段接入 `src/views/IdentityView.vue`，菜单改为“身份审核”。列表支持加载、失败重试、空状态和上下页；案件按需读取姓名、学号及合成学生卡；通过/驳回含二次确认、版本提交、可读回执，已处理和未知状态只读。驳回原因及建议去空白后必填；提交中阻止重复操作，同内容失败重试沿用幂等键。409 清空旧决定并重新读取当前案件，不自动重提。

详情、表单、卡图和回执均为组件短暂状态。切案、翻页、刷新列表、关闭案件、离开及会话/权限变化清理资料并取消请求，以本地代次拒绝晚到响应；blob 地址在收起、图像加载失败及清理时 revoke。401 清会话；403 清资料并交给现有拒绝页导航。后端错误正文不直接展示。服务层仅含合成数据，无真实网络或持久存储；离开页面后重入重置模拟案件，与真实审核持久性不同。

服务边界阶段验证为 32 个业务用例通过；页面阶段验证为 46 个业务用例（新增14个组件用例）及58个规则用例通过，`pnpm format`、`pnpm check`、`pnpm build` 通过。浏览器已观察到合成审核通过回执及版本2，截图保存在本地临时目录；不作为真实身份审核验收证据。人工步骤见 `docs/T012-integration.md`。同步中英文 README 的产品介绍与模拟选项，契约仍为0.1.0，无新增依赖。

当前完成的是本地合成业务开发。D02/T008/T011、真实案件权限/审计/版本并发与卡图响应仍待联调，未完成真实集成验收。后续管理端业务按 T017 → T028 → T030 → T032 依赖顺序继续拆分实现，Mock 与真实状态须分别记录。

## 业务服务边界（2026-10-21）

用户授权先完成业务开发，覆盖此前等待 T011 后再实施页面的推进安排；真实接入验收条件不变。关联 REQ-002/018/019，共享契约 0.1.0，分支 `codex/identity-review`。

第一阶段交付 `src/types/identity.ts` 和 `src/services/identity.ts`：脱敏游标列表、授权案件详情、本地合成卡图、approved/rejected 决定及 Verification 回执。每次操作重新核对本地权限，驳回原因及建议去空白后必填，版本或状态冲突返回 409；同幂等键同内容回放回执，异内容冲突，回放前重验权限。边界校验采用字段白名单，完整身份不会混入列表。

服务实例由页面持有，不进入共享 store 或浏览器持久存储。仅 DEV 且显式启用 Mock 时可用，没有真实网络调用；合成图仅展示演示标记。生产入口失败关闭。该客户端不代表后端持久幂等、审计或案件授权已经实现；D02/T008/T011 和学生卡二进制类型/大小/缓存头的真实联调仍待交付。真实适配器本阶段不启用。

验证：服务行为测试覆盖分页投影、边界格式、驳回必填、回执、幂等/版本冲突、权限收回、取消请求、未知案件、无网络及生产禁用。格式、检查及生产构建结果随本阶段提交记录。

历史阶段记录，迁移自 README；验证结果描述该阶段，不代表后续重新验收。共享契约版本：0.1.0。
